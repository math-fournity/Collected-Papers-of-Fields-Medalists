# Collected Papers of Fields Medalists

菲尔兹奖得主获奖作品论文收藏库。**68/68（1936–2022）全员覆盖 + 2026 年新科 4 人扩展 = 72 人**。

## 目录规范

- 每人一个目录：`<获奖年份>年 - <姓名>`；
- 文件类型：获奖论文**原文/全译本**（核心件）、ICM 官方工作报告、IMU citation/laudatio 颁奖词、
  ICM 会议论文、勘误/Addendum、姐妹篇、MinerU OCR 衍生件（`*.md` + `*_mineru*/`）；
- 共享论文（如 Duminil-Copin–Smirnov honeycomb）同时放入两人目录。
